## Execution Guide

### Prerequisites
- MongoDB running locally at `mongodb://localhost:27017`
- Node.js (v18+)

### 1. Start Server
```bash
cd server
npm install
npm start
```
Server runs on `http://localhost:5000`.

### 2. Start Client
```bash
cd client
npm install
npm run dev
```
Client runs on `http://localhost:5173`.
